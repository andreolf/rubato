Rubato connector for Claude

Speed up a video dynamically from a conversation: slow for the takeaways, fast through the filler and silence. Nothing is cut and voices keep their pitch.

Set it up

Rubato is listed in Claude's connector directory.

  1. Open claude.ai/directory/rubato, or in Claude go to Settings → Connectors, browse the directory and search “Rubato”.
  2. Choose Connect. There is no sign-in and no account.

In other MCP clients, or to add it by hand, use the server address below. It speaks MCP over streamable HTTP.

{{SITE_URL}}/mcp

What you need

  • A direct, public link to a video or audio file (MP4, MOV, WebM, MKV, MP3, M4A, WAV). A link to a page that plays the video will not work.
  • A recording of at most {{MAX_MINUTES}} minutes and {{MAX_MB}} MB, with speech in it.

For a file on your computer, use the upload box, or run Rubato locally with the skill, local MCP server or command-line tool, which have no length limit.

Use it

Give Claude the link and say what you want. For example:

  • “Speed up this talk with Rubato: https://example.com/talk.mp4”
  • “Use Rubato on https://example.com/meeting.mp4 with a 1.3x baseline and tell me what it slowed down for.”
  • “Make this lecture shorter without cutting anything, and keep the key points at normal speed: https://example.com/lecture.mp4”

Claude starts the job, waits for it, and replies with the new length, the time saved, the passages that were slowed down or sped up, and a download link.

Tools

ToolTypeWhat it does
speed_up_videoWriteStarts a job from a link. Options: base (ordinary passages, default 1.2), slow (takeaways, lists, key numbers, default 1.0), fast (filler, default 1.5), silence (dead air, default 2.0), language (spoken language code, detected if blank). Returns a job id.
get_resultRead-onlyReports the stage of a job. When it is done, returns the original and new length, time saved, average speed, the recognised passages with their speeds, and a download link.

How it decides

Rubato finds pauses from the audio, transcribes the speech, and recognises sentences that announce a takeaway, start or continue a list, or carry key numbers. Those stay at the slow speed. Logistics and hesitation get the fast speed, and dead air the fastest. The video is re-timed with ffmpeg; no content is generated or removed.

Limits and data

  • One job runs at a time, so a job may wait in a queue.
  • The built-in phrases are English. Other languages are transcribed, but fewer passages are recognised.
  • The downloaded file is deleted as soon as processing ends; the result is deleted after 30 minutes. See the privacy policy.
