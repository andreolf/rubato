Privacy policy

Applies to the Rubato website, its upload tool, its HTTP API and its hosted connector (MCP endpoint). Last updated 28 November 2026.

What Rubato receives

The video or audio file you upload, or the file behind a link you give to the connector, plus the speed settings you choose. Rubato has no accounts and does not ask for your name or email.

What happens to your file

  • The file is processed automatically on the server: it is analysed, transcribed by a speech-to-text model running on the same server, and re-rendered at dynamic speed.
  • The original file is deleted as soon as processing ends.
  • The result and its transcript are deleted 30 minutes after processing ends. Until then, anyone who has the result link can download it.
  • Files and transcripts are not used to train models, not sold and not shared with third parties.

Hosting and logs

The service runs on Hugging Face Spaces. Like any web host, the hosting provider may keep technical logs such as IP addresses and request times. Rubato itself keeps no log of who uploaded what.

Usage counts

To see whether the service is used and where it fails, Rubato counts events itself: page views, the site a visit came from, whether the page was scrolled or clicked, which of its buttons and links were used, roughly how long it stayed open, whether the device is a phone, tablet or computer, jobs started and finished, downloads, and for each job its length, how long it took, the language setting and, if it failed, the kind of failure. These counts are kept without a time limit.

  • File names, links, transcripts and the content of recordings are never part of these counts.
  • IP addresses and browser details are not stored. To count visitors, they are turned into a short code using a random key that exists only in the server's memory and is replaced every day, so the code cannot be traced back to you or followed from one day to the next.

Cookies and tracking

Rubato sets no cookies and uses no third-party analytics or advertising trackers.

Sensitive recordings

This is a public demo. Do not send confidential recordings to it. For those, run Rubato on your own machine with the open-source command-line tool, skill or local MCP server, where nothing leaves your computer.
